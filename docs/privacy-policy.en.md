# PasteScribe Privacy Policy

Last updated: November 8, 2026

PasteScribe is a Chrome extension that types text you paste into it, letter by letter, into the text field of the active tab.

## What data the extension handles

- **The text you paste into the extension.** It is used only to type it into the field you choose. It is kept in the browser's session memory so you don't lose it if you close the panel, and it is erased when you close the browser.
- **Your settings** (typing speed and the irregular-pauses option). They are stored in your browser's local storage.

## What it does NOT do

- It does not collect, sell or share personal data or browsing history.
- It does not send any data to any server: it makes no network requests.
- It uses no cookies, analytics, advertising or third-party services.
- It does not read the content of web pages: it only types into the text field you have selected, and only in the active tab when you press the extension's button.

## How to delete your data

Uninstalling the extension removes all of its settings. The session text disappears when you close the browser.

## Changes to this policy

If these practices change, this document and the date above will be updated.
